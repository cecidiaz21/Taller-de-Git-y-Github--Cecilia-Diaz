# 🛍️ Tienda Online - Cecilia Diaz

Una tienda online moderna y funcional desarrollada como proyecto educativo en el taller de Git y Github.

## 📋 Descripción

Este proyecto es una aplicación web completa de una tienda online, desarrollada con tecnologías web estándar (HTML, CSS y JavaScript). La plataforma proporciona una experiencia de compra intuitiva y segura con múltiples páginas y funcionalidades.

## ✨ Características Principales

### 🏪 Catálogo de Productos
- Visualización atractiva de productos
- Navegación fácil e intuitiva
- Diseño responsive adaptado a cualquier dispositivo

### 🛒 Carrito de Compras
- Agregar y eliminar productos dinámicamente
- Cálculo automático de totales
- Persistencia de datos en el navegador (localStorage)

### 👥 Perfil de Usuario
- Gestión de información personal
- Historial de compras
- Preferencias y configuración

### 📄 Políticas y Normativas
- **Políticas de Privacidad**: Información detallada sobre protección de datos
- **Normas de Uso**: Términos y condiciones de la plataforma
- **Política de Devoluciones**: Proceso claro y transparente

### 🔒 Seguridad y Privacidad
- Validación de datos de entrada
- Protección de información personal
- Cumplimiento de estándares web

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica de la aplicación
- **CSS3**: Estilos modernos y diseño responsive
- **JavaScript**: Interactividad y lógica de negocio
- **LocalStorage**: Almacenamiento de datos del cliente

## 📁 Estructura del Proyecto

```
├── index.html                      # Página principal de la tienda
├── normas.html                     # Términos y condiciones
├── politicas_de_privacidad.html    # Política de privacidad
├── styles.css                      # Estilos globales
├── script.js                       # Lógica principal de la tienda
├── privacidad.js                   # Funcionalidad de privacidad
├── img/                            # Carpeta de imágenes
└── README.md                       # Este archivo
```

## 🚀 Cómo Usar

1. **Accede a la tienda**: Abre `index.html` en tu navegador o visita https://cecidiaz21.github.io/Taller-de-Git-y-Github--Cecilia-Diaz/

2. **Explora los productos**: Navega por el catálogo y conoce todos los productos disponibles

3. **Realiza compras**: 
   - Selecciona los productos que desees
   - Agrégalos al carrito
   - Revisa tu pedido

4. **Lee nuestras políticas**: 
   - Consulta nuestras políticas de privacidad
   - Revisa los términos y condiciones

## 💡 Funcionalidades Destacadas

### Carrito Dinámico
El carrito se actualiza en tiempo real con los productos seleccionados, mostrando:
- Cantidad de artículos
- Precio unitario y total
- Opciones para modificar cantidades o eliminar items

### Almacenamiento Local
Los datos de tu sesión se guardan automáticamente en el navegador, permitiendo:
- Mantener tu carrito incluso si cierras el navegador
- Acceso rápido a tus preferencias

### Interfaz Responsiva
El diseño se adapta perfectamente a:
- 📱 Dispositivos móviles
- 💻 Tablets
- 🖥️ Pantallas de escritorio

## 📱 Compatibilidad

- Navegadores modernos (Chrome, Firefox, Safari, Edge)
- Sistemas operativos: Windows, macOS, Linux, iOS, Android
